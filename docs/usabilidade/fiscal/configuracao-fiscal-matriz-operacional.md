# Configuração Fiscal da Matriz — Uso Operacional

Acesse:

**Fiscal → Central Fiscal → Configuração Fiscal da Matriz**

A tela permite definir:

- regime tributário;
- UF de origem;
- contribuinte do ICMS;
- consumidor final padrão;
- situação ativa/inativa;
- observações.

A matriz é determinada automaticamente pelo contexto do usuário.

Somente configuração ativa é utilizada pelo Motor Fiscal.

Configuração inativa continua acessível nesta tela para edição ou reativação.
