# Documentacao de Usabilidade

Esta pasta concentra os manuais operacionais do Cashback System.

A documentacao de usabilidade explica como cada perfil utiliza as telas e
processos do sistema. Ela nao substitui a documentacao tecnica de arquitetura.

## Padrao dos manuais

Cada manual deve apresentar:

1. objetivo;
2. perfis autorizados;
3. caminho de acesso;
4. campos e informacoes;
5. passo a passo;
6. regras importantes;
7. mensagens e alertas;
8. exemplos;
9. erros comuns;
10. resultado esperado.
