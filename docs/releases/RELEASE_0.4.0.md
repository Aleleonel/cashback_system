# Cashback System v0.4.0

## Tipo da versão

Release estável de produção.

## Marco principal

Consolidação do PDV-04.

## Entregas

- frente de caixa;
- abertura e fechamento de caixa;
- histórico de fechamentos;
- histórico e detalhamento de vendas;
- numeração sequencial de vendas;
- cupom comercial não fiscal de 80 mm;
- permissões finas do PDV;
- controles contra sessões duplicadas;
- testes automatizados;
- documentação oficial;
- infraestrutura de diagnóstico, validação, release e rollback.

## Branches

- `master`: produção;
- `develop`: desenvolvimento estável;
- `feature/*`: desenvolvimento isolado.

## Tag

`v0.4.0`
